## Top 10 Useful VS Code Shortcuts

### Navigation

| Shortcut | Action | Why I Find It Useful |
|---|---|---|
| `Ctrl + P` | Quick Open / Go to File | Quickly opens files without searching through the Explorer. |
| `Ctrl + Shift + O` | Go to Symbol | Quickly jumps to a function, class, or symbol inside a file. |
| `Ctrl + G` | Go to Line | Jumps directly to a specific line number. |

### Editing

| Shortcut | Action | Why I Find It Useful |
|---|---|---|
| `Alt + Click` | Add Multiple Cursors | Allows editing multiple locations at the same time. |
| `Ctrl + D` | Add Selection to Next Find Match | Quickly selects the next occurrence of the current word for editing. |
| `Shift + Alt + Down` | Copy Line Down | Quickly duplicates the current line. |

### Debugging

| Shortcut | Action | Why I Find It Useful |
|---|---|---|
| `F5` | Start Debugging | Starts the debugger without navigating through menus. |
| `F9` | Toggle Breakpoint | Quickly adds or removes a breakpoint while debugging. |

### Terminal Commands

| Shortcut | Action | Why I Find It Useful |
|---|---|---|
| `Ctrl + \`` | Toggle Integrated Terminal | Opens or hides the terminal without leaving VS Code. |
| `Ctrl + Shift + \`` | Create New Terminal | Quickly opens another integrated terminal. |

## Most Useful Shortcuts in Daily Work

The shortcuts I expect to use most often are `Ctrl + P`, `Alt + Click`, `Ctrl + D`, and `Ctrl + \``.

`Ctrl + P` is useful when working with projects that contain many files because it allows me to quickly open a file. `Alt + Click` and `Ctrl + D` are useful when making the same change in multiple places. The terminal shortcuts are useful because I frequently need to run commands while developing without leaving VS Code.

## How Keyboard Shortcuts Improve Productivity

Keyboard shortcuts reduce the amount of time spent moving between the keyboard and mouse or navigating through menus. They make common actions faster and help maintain focus while coding.

Using shortcuts for navigation, editing, debugging, and terminal operations can make development more efficient, especially when working on larger projects. Over time, remembering frequently used shortcuts can reduce repetitive actions and make the development workflow smoother.

## Reflection

Learning VS Code shortcuts showed me that small improvements in everyday actions can make a noticeable difference in productivity. Multiple cursors are particularly useful because they allow several similar changes to be made at once.

I think the most important shortcuts for my daily work will be quick file navigation, multiple cursors, code editing shortcuts, debugging shortcuts, and the integrated terminal shortcuts.
